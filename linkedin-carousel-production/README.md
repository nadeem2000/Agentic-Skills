# LinkedIn Carousel Production

Reusable skill for turning ideas, reports, articles, newsletters, research, campaign material, and existing content into LinkedIn document carousels.

## Use cases
The skill builds a swipe narrative, preserves source evidence, creates mobile-readable slide copy, defines visual direction, packages the post for LinkedIn, and can use Canva when suitable design tools are available.

## Operating modes

### Full production
Develop the narrative and copy, create or adapt the visual design using available design tools, review the result, and prepare the final carousel file when export is supported.

### Content + design specification
When direct production is unavailable or unnecessary, produce:
- slide-by-slide copy;
- slide-by-slide layout direction;
- visual system and page specifications;
- brand guidance;
- document title;
- LinkedIn caption;
- CTA;
- evidence/source notes;
- preflight checklist.

## Inputs
The skill can start from a topic, rough idea, article, webpage, report, research paper, newsletter, policy brief, evaluation finding, campaign brief, existing carousel, or supplied brand assets.

## Default format
The practical design default is **1080 × 1350 px (4:5 portrait)**. This is a mobile-friendly production convention, not a mandatory LinkedIn PDF dimension.

For LinkedIn posting, prefer a **PDF document post** and supply a document title plus accompanying post caption.

## Example requests
- Turn a long evaluation report into an 8-slide carousel for development-sector leaders. Lead with the most decision-relevant finding and preserve the evidence.
- Create a professional carousel explaining five practical uses of AI in development organizations and create the design in Canva when available.
- Repurpose a newsletter into seven slides, keeping the strongest statistics and applying supplied brand colors and logo.
- Redesign an existing carousel so the first slide is stronger, body pages are less text-heavy, and the CTA is clearer.

## Typical narrative
**Hook → why it matters → core insights → evidence/example → practical implications → synthesis → CTA**

The skill does not force a fixed slide count.

## Accuracy
For factual carousels, use authoritative sources and do not invent claims or statistics. Platform specifications can change, so verify current requirements against LinkedIn Help whenever exact current limits matter.
