# LinkedIn Carousel Production Playbook

Use this reference with `linkedin-carousel-production`.

## 1. Think in swipes, not pages
A carousel is a sequence of micro-decisions. Each slide should give the reader a reason to continue.

A useful sequence is:
- **Hook:** a specific promise, tension, surprising fact, question, or strong point of view.
- **Orientation:** explain what the reader will understand or gain.
- **Development:** move through 3–6 distinct insights, steps, mistakes, findings, examples, or arguments.
- **Application:** show what the information means in practice.
- **Synthesis:** compress the message into a memorable takeaway.
- **CTA:** invite one clear next action.

Do not pad a carousel to a fixed slide count. Do not place a paragraph on every page merely to create more swipes.

## 2. Hook patterns
Good hooks are concrete and useful. Examples:
- “5 reasons your proposals keep losing before technical evaluation”
- “Pakistan’s water problem is not only scarcity”
- “What 27 evaluations reveal about programme sustainability”
- “Before you add AI to your NGO, fix these 4 workflows”
- “A practical framework for turning donor intelligence into a bid pipeline”

Avoid empty hooks such as “You won’t believe this,” generic motivational lines, or unsupported claims.

## 3. Slide-copy discipline
### Cover
Use one short headline and, if needed, one clarifying subhead. Add author/organization identity discreetly.

### Body slides
Prefer:
- one headline;
- 1–3 short supporting blocks;
- one statistic, quotation, diagram, example, or visual anchor where it adds meaning.

As a practical guide, keep most body slides well below roughly 60–80 words. This is not a hard platform limit; readability should decide.

### Closing slide
Use one conclusion and one CTA. Do not stack several unrelated asks.

## 4. Narrative patterns
Choose the pattern that fits the content.

### How-to
Hook → problem → steps → example → checklist → CTA

### Evidence-led insight
Finding → context → evidence → interpretation → implications → action

### Framework
Problem → framework overview → component slides → worked example → summary

### Myth vs reality
Myth → why it persists → evidence → corrected interpretation → what to do instead

### Case study
Challenge → intervention → approach → result → lesson → transferable takeaway

### Report/newsletter repurposing
Executive insight → 3–5 most decision-relevant findings → implications → recommended actions → source note

## 5. Design system
### Default canvas
Use **4:5 portrait, 1080 × 1350 px** as the default production size because it is mobile-friendly and easy to reuse as social imagery. This is a design convention, not an official LinkedIn requirement for PDF document posts.

### Hierarchy
Every slide should have a clear first, second, and third reading level:
1. headline;
2. core message/visual;
3. supporting detail/source/footer.

### Grid and spacing
- Keep safe margins consistent.
- Use a repeatable grid.
- Align text and visual elements deliberately.
- Leave enough negative space for comprehension, but avoid accidental empty areas caused by weak composition.

### Typography
- Use no more than two type families unless a brand system requires otherwise.
- Make headlines visually dominant.
- Avoid small body text that only works when zoomed.
- Maintain sufficient contrast.

### Visuals
Use visuals to explain, compare, orient, or reinforce. Suitable elements include:
- photographs with a clear role;
- simple diagrams;
- charts;
- timelines;
- maps;
- icons used sparingly;
- illustrations consistent with the brand.

Avoid decorative clutter, generic AI imagery, random icon clouds, and repeated stock-photo treatment.

## 6. Cross-slide continuity
A visual element may intentionally continue across two adjacent slides: an arrow, line, object, image crop, number sequence, or headline fragment. Use this only when it strengthens the swipe experience.

If using Canva or another design tool, duplicate the relevant element and align it precisely across pages. Do not rely on cross-slide continuity for essential information because users may view or download individual pages.

## 7. Brand handling
When the user supplies a brand kit, logo, colors, templates, or existing design:
- treat them as the primary visual constraints;
- preserve logo proportions and clear space;
- avoid introducing unapproved colors or type styles without a reason;
- use the brand identity consistently across all pages.

When no brand exists, create a restrained system with one primary accent, neutral support colors, and consistent typography. Do not invent an organization logo.

## 8. Evidence and citations
For factual carousels:
- identify the original source before writing the claim;
- prefer official datasets, institutional reports, policy documents, peer-reviewed research, or other authoritative primary sources appropriate to the subject;
- keep statistics, dates, units, geography, and denominators intact;
- distinguish evidence from interpretation;
- never fabricate a quotation or source.

For a dense evidence carousel, use short source labels or footnotes on relevant slides and provide fuller source notes in the caption or a final reference page when appropriate.

If the user supplied a report, do not add outside facts unless they materially improve the piece or the user asks for broader research.

## 9. Canva production path
When Canva tools are available and full production is requested:
1. Establish whether the user wants an existing brand kit/template or a fresh design.
2. Create a design brief containing audience, objective, slide sequence, exact copy, visual language, page size, and branding.
3. Generate or create the design through the appropriate Canva creation action.
4. Convert the selected candidate into an editable design when the Canva workflow requires it.
5. Review every page for text fit, clipping, hierarchy, spacing, alignment, brand consistency, and sequence.
6. Edit clear defects rather than accepting the first generated result.
7. Export or prepare PDF when the available Canva actions support export.
8. Confirm that a real design/file exists before describing the carousel as finished.

If the available Canva tooling cannot reliably make a complete multi-page document carousel, deliver the content + design specification and clearly state what remains to be assembled.

## 10. LinkedIn document-post baseline
Verify current requirements against LinkedIn Help when publishing instructions need to be exact. At the time this playbook was written (10 August 2026), LinkedIn Help states:
- supported document types include PDF, PPT/PPTX, and DOC/DOCX;
- document uploads may be up to 100 MB and 300 pages;
- only one document can be attached to a post;
- a document title is required;
- LinkedIn recommends converting to PDF where possible for quality;
- multi-layer PDFs should be flattened/merged;
- all pages in a PDF should use the same page size;
- video/animation inside documents displays as static content;
- post text is limited to 3,000 characters.

Do not turn these current values into timeless rules. Re-check the official platform if the user asks for current specifications.

## 11. LinkedIn caption structure
The caption should complement the carousel, not repeat every slide.

A strong structure:
1. one-line hook;
2. 2–4 lines of context;
3. one sentence explaining what the carousel covers;
4. one CTA;
5. optional concise source/credit note;
6. only relevant hashtags, if useful.

Keep it natural and readable. Do not overload the caption with hashtags.

## 12. Accessibility
- Use strong contrast and readable type.
- Do not encode meaning through color alone.
- Avoid extremely dense text.
- Provide text equivalents for essential chart or image meaning within the slide or caption.
- Keep source labels legible.
- Remember that viewers may download the document as PDF.

## 13. Final preflight
### Content
- Is the promise clear by slide 1–2?
- Does every slide earn its place?
- Is the sequence logically ordered?
- Are claims traceable?
- Is the CTA singular and relevant?

### Design
- Is text readable on a phone?
- Are margins/grid consistent?
- Are any elements clipped or misaligned?
- Are visual styles coherent?
- Is whitespace intentional rather than accidental?

### File/package
- Are all pages the same dimensions?
- Is the page order correct?
- Is the final file actually available?
- Is the document title supplied?
- Is the LinkedIn caption supplied?
- Has the final PDF been flattened/checked where necessary?
